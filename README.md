# תומכי תורה — מערכת ניהול ישיבת דעת אהרן

יישום Windows בעברית לניהול הזמנות, מעקב, מלאי, ספקים, משימות ודוחות עבור תומכי תורה — ישיבת דעת אהרן.

## יכולות בגרסה 3.2
- מסד נתונים מקומי SQLite לשמירת תמונת הנתונים של סביבת העבודה.
- שמירת עד 30 תמונות מצב קודמות, לכל היותר אחת בכל חמש דקות, ושחזור אוטומטי של תמונת JSON קודמת במקרה של זיהוי נתונים פגומים.
- סנכרון SQLite מאוחד בהשהיה קצרה של 450 אלפיות השנייה כדי למנוע כתיבות חוזרות בזמן רצף פעולות; סנכרון מיידי בעת הסתרת החלון או יציאה מהדף.
- דילוג על כתיבת SQLite כאשר תמונת הנתונים לא השתנתה, להפחתת פעולות דיסק וכתיבות WAL.
- בדיקת תקינות SQLite בעת הפעלת התוכנה וכתיבה בעסקה אטומית.

## יכולות המערכת
- לוח בקרה עם נתוני הזמנות, פריטים, הזמנות ממתינות, הזמנות שנמסרו, שווי הזמנות ואספקות באיחור.
- קטלוג מוצרים עם הוספה, שינוי שם ומחיקה מבוקרת.
- מאגר מזמינים אוטומטי: איחוד לפי שם, איתור לפי טלפון, סיכום היסטוריית הזמנות, כמויות, פעילות ושווי הזמנות; מעבר ישיר להזמנות של כל מזמין.
- שדות מותאמים אישית: מידה, צבע, גזרה וכל מאפיין אחר; סוגי שדות לבחירה, טקסט ומספר.
- רישום הזמנות לפי מזמין, מוצר, כמות, מאפיינים והערות.
- ניהול סטטוס לכל הזמנה: חדש, בטיפול, מוכן, נמסר או בוטל.
- תאריך אספקה צפוי ומחיר ליחידה; חישוב שווי שורת הזמנה וסך שווי ההזמנות.
- חיפוש וסינון לפי מוצר וסטטוס, ועדכון סטטוס ישירות בטבלת המעקב.
- סיכום כמויות לפי מוצר ושילובי מאפיינים.
- ייצוא ל-Excel (XLSX) או CSV.
- גיבוי ושחזור מלאים בקובץ JSON.
- חשבונות עבודה מקומיים נפרדים, עם יצירה, מעבר, שינוי שם ומחיקה.
- מספר הזמנה אוטומטי, שדה טלפון ועדיפות רגילה / גבוהה / דחופה.
- ניהול ספקים ופרטי קשר.
- ניהול מלאי לפי מוצר וספי התראה על מלאי נמוך.
- יומן פעילות מקומי לתיעוד יצירה, עריכה ושינויי סטטוס.
- מרכז חכם מקומי: שאילתות בשפה טבעית על נתוני ההזמנות, המלאי והעדיפויות באמצעות מנגנון ניתוח מבוסס כללים.
- מנהל משימות עם אחראי, תאריך יעד, השלמה ומחיקה; המשימות נשמרות בכל חשבון עבודה.
- בקרת תקינות נתונים לזיהוי הזמנות ללא לקוח, שיוך למוצר חסר, כמויות לא תקינות ומספרי הזמנה כפולים.
- כללי התראות מקומיים הניתנים להפעלה ולכיבוי עבור איחורים, מלאי נמוך והזמנות דחופות.
- עדכון סטטוס קבוצתי להזמנות מסומנות.
- מסננים מתקדמים למעקב לפי עדיפות ותאריך אספקה: באיחור, היום, שבעת הימים הקרובים או ללא תאריך.
- תצוגות מעקב שמורות לכל חשבון עבודה, כולל חיפוש, מוצר, סטטוס, עדיפות וטווח מועד האספקה; ניתן לטעון ולמחוק תצוגות.
- ארכיון הזמנות עם אפשרות שחזור.
- הדפסת דוח הזמנות ושמירה כ-PDF דרך חלון ההדפסה.
- שמירת נתונים מקומית במחשב; המידע אינו נשלח לשרת.
- טעינה עצלה של ספריית Excel רק בעת בקשת ייצוא, כדי לקצר את פתיחת התוכנה; אם אין חיבור לרשת, הייצוא עובר אוטומטית ל-CSV.
- רענון ממוקד של המסך הפעיל בלבד לאחר שמירה, במקום לבנות מחדש את כל המסכים בכל פעולה, להפחתת עומס ועבודה מיותרת.
- טבלת מעקב מדורגת: מוצגות עד 100 הזמנות בעמוד, עם מעבר בין עמודים ושמירת המסננים, כדי למנוע יצירת טבלה ענקית שמכבידה על המחשב.
- תהליך הבנייה משתמש במטמון לחבילות .NET ומבטל בניות ישנות מאותו ענף כדי לחסוך זמן ומשאבי CI.

## הורדה והתקנה
לאחר הצלחת תהליך הבנייה, קובץ ההתקנה `ClothingOrders-Setup.exe` מתפרסם בעמוד **Releases** של המאגר. פותחים את Releases, בוחרים את הגרסה האחרונה ומורידים את קובץ ה-EXE.

המתקין כולל את קובצי התוכנה ומתקין את Microsoft Edge WebView2 Runtime אם נדרש. מיועד ל-Windows x64.

## הרצה מתוך קוד המקור
נדרש .NET 10 SDK:
```powershell
dotnet restore src/ClothingOrders/ClothingOrders.csproj
dotnet run --project src/ClothingOrders/ClothingOrders.csproj
```

הנתונים נשמרים בפרופיל המקומי של WebView2 תחת LocalAppData. מומלץ להוריד גיבוי JSON באופן תקופתי.


## הבהרה לגבי המרכז החכם
העוזר בגרסה זו מבצע ניתוח מקומי מבוסס כללים וחישובים ואינו מודל AI חיצוני. הנתונים נשארים במחשב ואינם נשלחים לשירות צד שלישי. חשבונות העבודה עדיין פרופילים מקומיים בדפדפן WebView2 ולא מערכת משתמשים מאובטחת. SQLite משמש בשלב זה לשמירת תמונת נתונים מלאה ולניהול היסטוריית שחזור מקומית; הנתונים העסקיים עדיין מנוהלים בממשק המקומי. הרשאות משתמש אמיתיות וסנכרון בין מחשבים טרם הוטמעו.
